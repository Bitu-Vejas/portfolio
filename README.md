# MB Bitų vėjas | Portfolio

Ši repozitorija saugo įmonės **MB Bitų vėjas** portfolio svetainės kodą. 
Svetainė skirta pristatyti mūsų klientams sukurtus projektus – nuo paieškos sistemų iki debesų platformų.

## 🚀 Projekto nuoroda

Svetainė bus pasiekiama adresu:  
`portfolio.googliukas.lt` *(šiuo metu laukiama serverio infrastruktūros atstatymo po DDoS atakos)*

Kol kas kodas talpinamas čia, GitHub, demonstruojant versijų kontrolės praktikas.

## 🧩 Turinys

- **14 aktyvių projektų** (SearXNG, ONLYOFFICE, Pastorale Nova, GoogleCloud.lt ir kt.)
- Dinaminis projektų tinklelis
- Automatinės nuorodos į kiekvieną gyvą svetainę
- Integracija su GitHub profiliu (`Bitu-Vejas`)

## 🛠️ Technologijos

- HTML5 / CSS3
- JavaScript (dinaminis turinio generavimas)
- Font Awesome ikonos
- Responsive dizainas (veikia telefonuose)

## 📂 Kaip paleisti lokaliai?

1. Atsisiųskite `index.html`
2. Dukart spustelėkite failą – jis atsidarys naršyklėje
3. Viskas veikia be serverio (statika)

## 🤝 Apie mus

**MB Bitų vėjas** – debesų technologijų ir web sprendimų kūrimo įmonė.  
Kuriame individualius sprendimus: nuo paieškos variklių iki asmeninių debesų platformų.
